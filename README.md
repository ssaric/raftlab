# Raftlab

An interactive simulation of the [Raft consensus algorithm](https://raft.github.io/raft.pdf).

Not an animation you watch — a cluster you operate. Crash servers, partition the
network, delay or drop individual RPCs, add and remove members, and see what the
protocol does about it. Rewind, change one decision, and watch a different
history play out.

Available at https://raft.njanjo.com.
